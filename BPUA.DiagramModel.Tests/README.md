# BPUA.DiagramModel.Tests

This test project demonstrates the first practical use of `BPUA.DiagramModel`.

The test creates a small Account use case diagram in code, validates it, saves it to JSON, loads it back, and validates the loaded model again.

Generated JSON location during a test run:

```text
BPUA.DiagramModel.Tests/bin/Debug/net9.0/GeneratedDiagrams/AccountUseCaseDiagram.json
```
